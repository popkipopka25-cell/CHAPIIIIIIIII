# Настройка веб-панели Чапи

1. Загрузите весь ZIP проекта в репозиторий/сервис, где запускается бот. Панель уже встроена в тот же Python-процесс и использует ту же базу.
2. В Render откройте сервис → **Environment** и добавьте переменные:
   - `TELEGRAM_BOT_TOKEN` — токен бота (секрет, не отправляйте его в чаты).
   - `OWNER_TELEGRAM_ID` — ваш числовой Telegram ID.
   - `PANEL_PASSWORD` — новый уникальный пароль для сайта длиной минимум 12 символов, не пароль Telegram.
   - `PANEL_SESSION_SECRET` — отдельная случайная строка минимум из 32 символов, не совпадающая с паролем и токеном.
   - `DB_PATH=/var/data/bot.db` — если постоянный диск Render смонтирован в `/var/data`.
3. Подключите постоянный диск к Render и убедитесь, что путь `DB_PATH` находится внутри точки монтирования. Без диска локальная SQLite-база может исчезнуть при пересоздании сервиса.
4. Перезапустите/разверните сервис и откройте основной HTTPS-адрес. Панель открывается на `/` и `/panel`; `/health` предназначен для проверки состояния сервиса.
5. Войдите с `PANEL_PASSWORD`. Токен Telegram-бота в форму входа вводить нельзя.

## Что доступно

- статистика пользователей, групп, кланов, наказаний, заметок и спам-блока;
- включение/выключение модулей глобально;
- включение/выключение настроек отдельно для каждой зарегистрированной группы;
- назначение и снятие глобальных ролей агента/администратора;
- добавление пользователей в глобальный спам-блок и снятие блокировки;
- журнал действий глобального штата.

Изменения пишутся в общую базу бота. Панель не может показывать группы, пока бот не увидел сообщения в этих группах и не создал записи настроек.
