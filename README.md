# Чапи — Telegram-бот для групп

Русскоязычный Telegram-бот для групп. В проекте реализованы профили, модерация, антиспам, заметки, экономика, браки с подтверждением обеих сторон, система кланов и личная панель владельца с настройками групп и управлением агентами. Это самостоятельная реализация похожих категорий функций, а не оригинальный исходный код Iris. Полный интеграционный запуск с Telegram API необходимо проверить после установки зависимостей и настройки токена.

## Быстрый запуск (без программирования)

1. **Получите токен**: откройте @BotFather в Telegram → `/newbot` → придумайте имя → скопируйте токен.
2. **Узнайте свой ID**: напишите @userinfobot — он покажет ваш числовой ID.
3. **Запустите проект** одним из способов ниже.

### Вариант А: на своём компьютере

```bash
pip install -r requirements.txt
cp .env.example .env
# откройте .env и вставьте TELEGRAM_BOT_TOKEN и OWNER_TELEGRAM_ID
python main.py
```

### Вариант Б: на платформе (Railway, Replit, PythonAnywhere и т.п.)

1. Загрузите файлы проекта на платформу.
2. В разделе переменных окружения (Environment / Secrets) добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather (старое имя `BOT_TOKEN` тоже поддерживается)
   - `OWNER_TELEGRAM_ID` — ваш числовой ID (старое имя `OWNER_ID` тоже поддерживается)
3. Команда запуска: `python main.py`

> Важно: бот хранит данные в файле SQLite (`bot_database.db`). Выбирайте платформу,
> которая сохраняет файлы между перезапусками (постоянный диск), иначе данные будут
> сбрасываться. На Replit файлы сохраняются; на бесплатном Railway — зависит от тарифа.
> Бесплатные тарифы обычно не гарантируют круглосуточную работу: приложение может
> «засыпать» без активности.

## Запуск через Docker

В каталоге проекта выполните `docker build -t chapi-bot .`, затем запустите контейнер с переменными `TELEGRAM_BOT_TOKEN` и `OWNER_TELEGRAM_ID`. Для сохранения данных подключите постоянный том к `/data` и задайте `DB_PATH=/data/bot_database.db` в переменных окружения. Не помещайте токен в Dockerfile или в публичный архив.

```bash
docker run -d --name chapi-bot --restart unless-stopped \
  --env-file .env -e DB_PATH=/data/bot_database.db \
  -v "$PWD/data:/data" chapi-bot
```

Перед запуском создайте локальный `.env` по образцу `.env.example`; настоящий токен не добавляйте в ZIP.

Для платформ с поддержкой worker-процессов добавлен `Procfile` с командой `python main.py`.

## Добавление бота в группу

1. Добавьте бота в свою группу как участника.
2. Назначьте его **администратором** с правами: удалять сообщения, блокировать участников, закреплять.
3. Напишите в группе `помощь` — бот ответит списком команд.

## Команды

Большинство команд работают обычным текстом без `/`, например:
`мут @username 10м флуд`, `варн @username спам`, `профиль`, `мой id`, `кто админ`, `инфо группы`, `баланс`, `брак @username`.
Полный список — команда `помощь` в чате с ботом. Для настроек группы используйте `настройки`, `настройка антиспам вкл` или `настройка антиспам действие mute`; текст приветствия меняется командой `приветствие текст &lt;текст&gt;`.

## Безопасность

- Токен хранится только в переменных окружения / `.env` (файл `.env` не попадает в архив и git).
- Владелец задаётся через `OWNER_TELEGRAM_ID` (для совместимости поддерживается `OWNER_ID`), никто не может сам себя назначить владельцем.
- Действия против пользователей с равной или более высокой ролью запрещены.

## Экономика (чапы)

- `баланс` / `баланс @user` — баланс чапов
- `бонус` — ежедневная награда (100 чапов, раз в 24 часа, проверка на сервере)
- `перевести @user 100` — перевод (одна транзакция, без минуса и двойных списаний)
- `топ` — топ-10 богачей
- `магазин`, `купить <товар>`, `инвентарь` — магазин и покупки
- `подарить @user <товар>` (или ответом на сообщение `подарить <товар>`) — передать одну единицу предмета
- `история` — последние операции
- `задания`, `задания забрать`, `достижения` — ежедневные цели, награды и достижения
- `премиум статус [@user]`, `премиум выдать @user 30д`, `премиум снять @user` — ручной премиум-статус группы; выдача/снятие только администраторами
- `статус`, `статус установить <текст>` — персональный статус до 80 символов для участников с активным премиумом
- Админы: `выдать @user 100`, `забрать @user 100`, `товар добавить <имя> <цена>`, `товар удалить <имя>`

## Восстановление брака

После развода можно в течение 3 дней написать `восстановить брак`. Бывший партнёр должен подтвердить запрос командой `принять восстановление брака`; при отказе — `отклонить восстановление брака`. Брак не восстанавливается без согласия обеих сторон.

## Дела и апелляции

- `жалоба @user <причина>` (или ответом на сообщение `жалоба <причина>`) — отправить дело модераторам без автоматического наказания.
- `обжалование <текст>` — участник может отправить апелляцию, если у него есть активное наказание. Апелляция не снимает наказание автоматически.
- `дела` — очередь ожидающих дел для модераторов и выше.
- `дело ID` — посмотреть дело.
- `дело принять ID [комментарий]` / `дело отклонить ID [комментарий]` — вынести решение.

## Автоответы

- `автоответ добавить привет => Привет, {name}!` — создать или обновить точный триггер (для модераторов и выше).
- `автоответы` — показать список триггеров.
- `автоответ удалить привет` — удалить триггер.
- Триггеры сравниваются без учёта регистра; ответ может содержать `{name}` для упоминания автора.
- Модуль можно отключить командой `настройка автоответы выкл`.

## Проверки

Офлайн-проверка без установки библиотек:

```bash
python tools/self_check.py
```

Полные тесты с временной SQLite-базой:

```bash
pip install -r requirements.txt
pytest
```

`self_check.py` проверяет синтаксис, шаблоны команд, базовую SQL-схему и миграции, но не заменяет интеграционный запуск Telegram. Тесты используют временную базу и не трогают настоящие данные.

## Структура проекта

- `main.py` — запуск
- `config.py` — настройки из переменных окружения
- `database.py` — база данных (автосоздание таблиц)
- `utils.py` — парсинг команд, роли, время
- `handlers/` — обработчики команд по модулям
- `tests/` — автоматические тесты

## Веб-панель владельца

После запуска откройте основной HTTPS-адрес сервиса (или `https://ВАШ-ДОМЕН/panel`) в Safari. Панель подключена к тому же приложению и базе данных, что и бот; доступные действия не являются демонстрационными.

В переменных окружения хостинга обязательно задайте:

- `PANEL_PASSWORD` — отдельный пароль от 12 символов для входа в веб-панель (не токен Telegram).
- `PANEL_SESSION_SECRET` — отдельная случайная строка минимум из 32 символов для подписи сессии.
- `OWNER_TELEGRAM_ID` — ваш числовой Telegram ID.

Не используйте примеры из `.env.example` как реальные секреты. Панель предоставляет обзор статистики, настройки групп, глобальные переключатели модулей, управление глобальным штатом, глобальный спам-блок и журнал. Сессия хранится в HttpOnly cookie и истекает через 8 часов. Для Render используйте HTTPS и постоянный диск для базы данных.
