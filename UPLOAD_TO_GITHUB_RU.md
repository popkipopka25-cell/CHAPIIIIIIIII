# Как загрузить Чапи в GitHub с iPhone

## Важно
Загружайте **содержимое архива**, а не сам ZIP-файл. В корне репозитория должны быть `main.py`, `config.py`, `database.py`, `requirements.txt`, `Dockerfile` и папка `handlers/`.

Внутри `handlers/` должны лежать файлы обработчиков, включая `__init__.py`. Не создавайте пустую папку `handlers` вручную.

## Перед загрузкой
1. Сохраните копию текущего репозитория или убедитесь, что ZIP остался в приложении «Файлы».
2. Распакуйте архив на телефоне.
3. Загрузите все файлы и папки из распакованного архива в корень репозитория `Chapi`.
4. Проверьте, что GitHub показывает `handlers` как папку рядом с `main.py`, а не внутри другой вложенной папки.
5. Дождитесь окончания загрузки и только потом проверьте Render.

## Настройки Render
Для запуска нужны переменные окружения `TELEGRAM_BOT_TOKEN` и `OWNER_TELEGRAM_ID`. Для веб-панели также нужны отдельные `PANEL_PASSWORD` и `PANEL_SESSION_SECRET`.

Не добавляйте токен в файлы проекта, README, скриншоты или публичные сообщения. Не присылайте его в чат.

## Ограничение проверки
Синтаксис Python и встроенная самопроверка проекта прошли в проверочной среде. Полный `pytest` и запуск с Telegram API не подтверждены: в этой среде не установлена зависимость `aiosqlite`. Перед использованием проверьте бота в отдельной тестовой группе.
