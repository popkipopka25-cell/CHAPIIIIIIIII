## Фактическое состояние проекта (chapi-etap4-economy)
- Python + aiogram 3.13 + aiosqlite, ~1870 строк.
- Тесты: `pytest` — **19 passed** (только экономика), запущено в этом этапе.
- Подключено: помощь, профиль, мут/размут, варн/варны/снять варн, бан/разбан/кик, роль, журнал, антиспам (ссылки/флуд), заметки, экономика (баланс, бонус, перевод, топ, магазин, купить, инвентарь, история, выдать/забрать, товар добавить/удалить).
- Таблицы marriages, proposals, clans, clan_* существуют в БД, **но обработчиков нет** — README ошибочно обещает браки и кланы.
- Нет: админ-панели владельца, агентов и полномочий, глобальной СпамБД, апелляций, глобального аудита, миграций (только CREATE IF NOT EXISTS), резервных копий.
- Владелец задаётся `OWNER_ID`; по ТЗ нужно `OWNER_TELEGRAM_ID` (будет поддержано оба на этапе 4).
